KORIX3D - APLIKACJA WINDOWS

1. Rozpakuj pobrany plik ZIP.
2. Uruchom plik "Zainstaluj KORIX3D.cmd".
3. Po instalacji użyj ikony "KORIX3D Produkcja" na pulpicie lub w menu Start.
4. Zaloguj się kontem administratora lub pracownika.

Aplikacja otwiera Centrum produkcji w osobnym oknie systemowym bez paska
adresu i kart przeglądarki. Wykorzystuje bezpieczny tryb aplikacji Microsoft
Edge (lub Google Chrome, jeżeli Edge nie jest dostępny).

Paczka nie zawiera haseł, kluczy API ani danych klientów.
Wymaga połączenia z internetem.
